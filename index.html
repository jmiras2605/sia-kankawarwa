📚 Sistema Integrado Académico

Plataforma académica para la Institución Educativa Indígena Kankawarwa.

El objetivo es que el docente pueda cargar la información académica y generar los boletines automáticamente.

Proceso de boletines:

1. Descargar la plantilla.

2. Llenar el Word.

3. Subir el Word.

4. Procesar la información.

5. Seleccionar el estudiante.

6. Generar el boletín.
